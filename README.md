Hub-and-Spoke Network Topology Project
An enterprise-level network design and simulation project utilizing a Hub-and-Spoke topology. Developed by Group: Suzuran.

🌐 Topology Overview
The network infrastructure connects the central HQ Data Center to four factory branches via Fiber Optic and Wireless Bridge connections:

    Smart EV Electronics Factory
    Smart Packaging Factory
    Automotive Assembly Plant
    Luminatech Smart Lighting Factory
